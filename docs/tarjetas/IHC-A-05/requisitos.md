# Requisitos, tarjeta IHC-A-05

| ID | Requisito | Criterio de aceptación |
|---|---|---|
| R1 | El menú muestra los productos agrupados por categoría. | Con 360 px de ancho, cada categoría tiene encabezado y no hay productos sueltos. |
| R2 | Cada acción sobre el pedido (agregar, cambiar cantidad, quitar) da feedback visible. | Tras cada acción aparece un mensaje de estado en menos de 1 segundo. |
| R3 | La pantalla Mi pedido siempre muestra el desglose y el total. | El total coincide con la suma de los subtotales en todo momento. |
| R4 | El presupuesto de USD 4,25 se muestra junto al total en todo momento. | Mi pedido muestra total y presupuesto restante tras cada cambio. |
| R5 | Si un cambio supera el presupuesto se avisa de forma clara en el momento. | Al superar 4,25 aparece un aviso con el exceso en dólares, también anunciado a lectores de pantalla. |
| R6 | Se ofrece ajustar el pedido manteniendo el carrito. | El aviso incluye 'Ajustar pedido' que conserva los productos y el total. |
