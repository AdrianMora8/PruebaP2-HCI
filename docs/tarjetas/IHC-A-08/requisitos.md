# Requisitos, tarjeta IHC-A-08

| ID | Requisito | Criterio de aceptación |
|---|---|---|
| R1 | En todo momento se identifica el paso actual del Stepper. | El paso activo tiene texto, ícono y foco visible, no solo color. |
| R2 | El checklist indica qué casillas están guardadas y cuáles no. | Cada casilla muestra su estado de guardado y el progreso total en porcentaje. |
| R3 | El procedimiento se lee antes de iniciar la prueba. | No se puede abrir el primer paso sin haber visto el procedimiento. |
| R4 | El procedimiento se muestra completo y breve antes de iniciar. | Una pantalla previa lista los pasos y exige pulsar 'Entendido' para empezar. |
| R5 | Las casillas conservan su estado al cambiar de paso. | Marcar, cambiar de paso y volver deja las casillas marcadas. |
| R6 | Se distingue lo guardado de lo no guardado y se muestra el progreso. | Cada casilla muestra 'Guardado' o 'Sin guardar' y hay barra de progreso con porcentaje. |
