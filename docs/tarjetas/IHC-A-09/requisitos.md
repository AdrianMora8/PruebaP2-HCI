# Requisitos, tarjeta IHC-A-09

| ID | Requisito | Criterio de aceptación |
|---|---|---|
| R1 | En todo momento se identifica el paso actual del Stepper. | El paso activo tiene texto, ícono y foco visible, no solo color. |
| R2 | El checklist indica qué casillas están guardadas y cuáles no. | Cada casilla muestra su estado de guardado y el progreso total en porcentaje. |
| R3 | El procedimiento se lee antes de iniciar la prueba. | No se puede abrir el primer paso sin haber visto el procedimiento. |
| R4 | Los participantes se identifican con un código seudónimo, nunca con su nombre. | El formulario no tiene campo de nombre real; solo 'Código de participante'. |
| R5 | El código se valida con un formato definido y el error es claro. | El formato P-NN (por ejemplo P-07) se valida y un valor inválido muestra el formato esperado. |
| R6 | Las evidencias y el resumen muestran solo el código. | Ninguna pantalla ni la exportación muestra nombres reales. |
