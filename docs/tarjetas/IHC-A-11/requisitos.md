# Requisitos, tarjeta IHC-A-11

| ID | Requisito | Criterio de aceptación |
|---|---|---|
| R1 | En todo momento se identifica el paso actual del Stepper. | El paso activo tiene texto, ícono y foco visible, no solo color. |
| R2 | El checklist indica qué casillas están guardadas y cuáles no. | Cada casilla muestra su estado de guardado y el progreso total en porcentaje. |
| R3 | El procedimiento se lee antes de iniciar la prueba. | No se puede abrir el primer paso sin haber visto el procedimiento. |
| R4 | A 360 px ningún elemento se superpone y todos los campos son visibles. | Con 360 px de ancho no hay solapamiento ni desplazamiento horizontal. |
| R5 | El Stepper y las tarjetas conservan una jerarquía clara en pantalla pequeña. | El Stepper queda arriba y cada tarjeta debajo, con espaciado consistente. |
| R6 | El orden del foco sigue el orden visual. | Tab recorre los elementos de arriba hacia abajo sin saltos. |
